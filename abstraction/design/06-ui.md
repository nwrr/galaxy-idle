# 06 — UI/UX (TUI)

> Render pakai `ratatui` + `crossterm` (lihat [`07-architecture.md`](07-architecture.md)).
> ASCII layout di bawah adalah target; UI responsif terhadap ukuran terminal. Color scheme &
> animasi dipakai untuk feedback status, bukan dekorasi semata.

## Prinsip

- **Jangan banjiri layar.** Bagi jadi panel; tampilkan net income agregat, sembunyikan detail di
  view khusus.
- **Render decoupled dari simulasi.** Simulasi 1 Hz; render ~10–15 FPS untuk animasi halus
  (lihat `07`). UI membaca snapshot `GameState`, tidak memutasinya.
- **Color = status**, bukan tema: merah=deficit/hazard, hijau=surplus/loot, kuning=event/trade.

## Responsive Breakpoints

```rust
pub enum LayoutMode { Full, Compact, Minimal }

fn layout_mode(width: u16, height: u16) -> LayoutMode {
    if width >= 100 && height >= 30 { LayoutMode::Full }     // sidebar + detail
    else if width >= 70            { LayoutMode::Compact }   // sidebar tipis, resource ringkas
    else                           { LayoutMode::Minimal }   // tab-based, navigasi key
}
```

Resize terminal → recompute layout tiap render. Di `Minimal`, sidebar diganti tab; navigasi
antar-view via key (lihat keybinding).

## Portrait Karakter (gambar, bukan ASCII)

Portrait NPC (Void Merchant, alien encounter, crew/quest giver) dirender sebagai **gambar PNG asli**
via `ratatui-image` — bukan ASCII (wajah butuh resolusi). Detail teknis di
[`07-architecture.md`](07-architecture.md) §Portrait.

- Muncul di panel dialog/merchant/event (mis. kotak kiri saat encounter), area ~44×32 sel.
- Terminal dengan Sixel/Kitty/iTerm2 → gambar tajam; terminal biasa → fallback Unicode half-block
  (tetap terbaca sebagai wajah).
- **Sprite celestial = ANSI half-block BERWARNA** (`.ans`) — warna per-biome (ocean biru, lava
  merah-oranye, gas giant band krem/oranye, dst.) agar biome jelas beda; 3 ukuran (sm/md/lg) × 3
  depth (tc/256/16, fallback warna). Banner/frame tetap teks. Lihat asset di `assets/`.

```
┌ VOID MERCHANT ─────────────┐
│ [▓▒ portrait PNG ▒▓]  "..." │   ← ratatui-image (StatefulImage) di area kiri
│  (Sixel/Kitty/halfblock)   │
└────────────────────────────┘
```

## Animasi Partikel (Galaxy View)

Frame-based, dijalankan oleh loop render (bukan simulasi):

```
Frame 1:          Frame 2:          Frame 3:
   *    ·            ·    *             *    ·
      ════              ════               ════
    ═■════          ═■════           ═■════
   ═/│\══          ═/│\══           ═/│\══
```

- `·` bergerak lambat; `*` twinkle (swap `·`↔`*`); `═` route pulse (`─`/`│` bergantian);
  `🚀` bergerak di jalur saat `Traveling` (posisi = `elapsed/total`).
- Animasi murni kosmetik; tidak mengubah state. Frame index = `render_frame % N`.
